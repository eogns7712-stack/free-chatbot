# 대화 시나리오 평가

프로젝트 루트에서 실행합니다. 학습이나 모델 수정은 하지 않습니다.

```powershell
.\.venv\Scripts\python.exe evaluation/evaluate_scenarios.py
```

입력은 fresh_dialogues_v1.json의20개 시나리오이며, 각 시나리오는 새 대화로 시작합니다.
모델이 만든 최근 두 문답을 전달합니다. 중간에 정답 답변을 넣지 않습니다.
기본 모델은 artifacts/three-turn-flow-v4/epochs/epoch-06입니다.
기본 출력 reports/fresh_dialogues_v1이 이미 있으면 덮어쓰지 않습니다.
재실행 시 --output reports/fresh_dialogues_v1_repeat 같은 새 폴더를 지정합니다.
answers.json은 자동 생성 원문, reviewed_answers.json은 별도 수동 판정 결과입니다.
질문 파일·토크나이저·가중치 해시와 환경을 기록합니다. 자동 pending은 판정 전 상태입니다.

새 질문은 기존 학습·검증·평가 대화와 전체 사용자 발화 순서의 정규화 정확 중복을 배제했습니다.
의미가 비슷한 질문은 포함하며 작은 개발 평가입니다. 모델 선택과 반복 보강에 사용하면 독립 최종 평가로 부르지 않습니다.
이전 시나리오와 질문·난도가 달라 점수 차이를 모델의 성능 저하로 해석하지 않습니다.
고양이·요리·색 회상은 현재 학습 범위 밖의 한계 진단입니다.
