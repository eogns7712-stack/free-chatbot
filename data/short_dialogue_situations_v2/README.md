# 상황별 단문 응답 v2

5주제, 각 3상황. 상황마다 짧은 답변 1개를 의미에 따라 배정했다.
학습 60개(상황별4), 검증15개(상황별1), 개발비교15개(상황별1).
probe_questions: 학습60 + 새 개발15 + 이전 개발20 = 95개.
v1의 epoch-05에서 추가 학습하는 단계적 확장 실험이다.
출발 모델과 데이터 구성이 v1 학습 실험과 달라 직접적인 단일 변수 비교가 아니다.
정확 일치는 보조 지표. 주제와 세부 상황의 관련성, 문장 품질을 별도로 판단한다.
retention의 reference는 이전 고정 답변이다. 새 답변이 문자열로 달라도 실패가 아니다.
한 질문으로 인식하기 애매한 사례는 수동 검토한다.
자유 대화, 주제 밖 질문, 다중 턴 기억은 아직 다루지 않는다.
이 평가 질문들은 매 회차 확인하는 개발용이며 독립 최종 시험이 아니다.
