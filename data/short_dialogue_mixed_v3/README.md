# 기존 문답과 상황 문답 혼합 v3

학습119개. 인사·피로·산책·영화 각24개, 식물23개. 동일 질문 1개를 중복 제거했다. v1 학습60개와 v2 학습60개를 함께 사용한다.
이전 질문은 그대로 유지하되 관람 계획, 재방문, 수면 부족, 분갈이 완료 등의 상황에 답변을 배정했다.
상황이 불명확한 질문에는 일반 답변을 유지했다. 표면적 유사 표현의 의미 중복까지 배제한 것은 아니다.
레코드 변경 이력은 manifest.json, 요약은 build_report.json에 있다.
v1/v2의 검증·평가 질문과 정규화 정확 중복이 없는지 확인했다. 새 학습 질문을 평가 실패 사례에서 만들지 않았다.
검증15개와 새 개발15개는 v2 파일 그대로 보존. 이전 개발20개도 계속 확인한다.
매 회차 학습119개와 개발35개, 총154개 답변을 생성한다.
retention의 이전 고정 답변과 달라도 주제와 상황에 맞으면 통과할 수 있다.
문자열 일치만으로 망각이나 대화 성능을 판단하지 않는다.
시작 모델은 v2 epoch-06. 옵티마이저는 새로 시작한다. 원 실험의 정확한 resume은 아니다.
학습량과 데이터 구성이 함께 달라지는 확장 실험이며, 단일 원인의 효과를 증명하지 않는다.
평가 질문은 반복 확인한 개발용이다. 자유 대화나 다중 턴 기억 능력을 검증하지 않는다.
