# 일상 주제 및 시점 대조 확장 v4

v3의 119개 원문·답변을 그대로 보존하고 72개 문답을 추가했다. 총191개.
음식(요리 계획/성공), 교통(지연/방향 착각), 집안일(청소 완료/빨래 정리)의 학습48개.
산책/영화/분갈이의 계획과 완료를 대조하는 24개 학습 문답.
검증은 기존15 + 일상12 + 시점6 =33개. v3 손실과 직접 비교할 수 없다.
시작 모델은 v3 epoch-06. 모델 가중치를 읽지만 옵티마이저는 새로 시작한다.
새40개 질문은 그대로 보존해 반복 개발 평가에 사용하며 학습에는 넣지 않는다.
기존 개발35개와 학습 원문 일부42개를 더해 매 회차117개 생성 답변을 기록한다.
문자열 불일치만으로 실패를 판정하지 않고 주제·상황·문장 이해 가능성을 수동 검토한다.
평가 문장과 정규화 정확 중복은 없으나, 상황과 의미가 비슷한 문장은 의도적으로 포함한다.
여러 요소가 동시에 달라지는 확장 실험이므로 원인 하나의 효과로 해석하지 않는다.
8주제 단문 응답 실험이며 자유 대화나 다중 턴 기억을 검증한 것이 아니다.
