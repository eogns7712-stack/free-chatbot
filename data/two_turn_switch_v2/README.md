# 주제 유지와 주제 전환 2턴 실험

기존 학습169개를 유지하고 전환60개 추가, 총229개.
5개 주제의 서로 다른 방향20개에 학습3개, 검증1개, 개발1개씩 구성.
명시적인 전환 표현과 표시 없는 새 주제도 학습한다. 정해진 전환 표시의 범위는 작다.
검증은 기존15+전환20=35개. 이전 검증 손실과 직접 비교하지 않는다.
개발 비교35개는 기존 후속15개와 새 전환20개. 기존 단문20개도 유지한다.
매 회차 기존45개+전환 학습20개+전환 개발20개+실제 사용자 사례2개=87개를 기록한다.
사용자가 시험한 두 문장은 학습과 검증에 넣지 않았다. 이미 관찰한 개발 사례로 취급한다.
answer는 정답 첫 응답 제공, rollout_answer는 모델의 첫 응답부터 생성한 실제 사용 조건.
시작 모델은 two-turn-dialogue-v1의 epoch-06. 옵티마이저는 새로 초기화한다.
고양이 등 새 주제, 3턴 이상, 장기 기억은 이번 범위에 포함하지 않는다.
다른 source에서 target으로 가는 질문을 공유하므로 독립적인 일반 대화 성능 시험은 아니다.
전체 대화의 정규화 중복은 없지만 첫 질문 및 전환 질문이 의도적으로 공유된다.
후속 응답 유지/전환 응답/기존 단문을 나눠 의미 관련성과 문장 품질을 판정한다.
