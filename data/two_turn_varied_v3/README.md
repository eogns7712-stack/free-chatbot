# 다양한 직전 응답의 후속 대화 v3

기존 주제 유지/전환229개 보존 + 문맥 변형70개 =학습299개.
새 문맥 변형에서는 마지막 assistant 답변만 학습한다. 첫 답변은 입력 문맥으로만 사용하여
동일 첫 질문에 여러 첫 답변을 정답으로 강제하는 충돌을 줄인다.
각 주제 첫 질문3종 x 직전 assistant 응답3종 x 후속 답변4종.
검증43개(기존35+신규8), 신규 개발8개. 일부 문맥과 뜻이 의도적으로 유사하다.
전체 대화의 정규화 정확 중복을 배제했지만 첫 질문/후속 표현은 일부 공유한다.
같은 주제에서 답변 후 종류를 다시 묻지 않고 받은 내용을 인정하는 것이 목표다.
난초·영화 제목의 지식을 추가하거나 이름을 그대로 출력하도록 학습하는 과제는 아니다.
데이지/제라늄의 실제 실패 문장은 학습과 검증에서 제외하고 회귀 평가에만 포함한다.
기존87개+신규 학습4개+신규 비교8개+회귀2개=101개를 회차별 기록한다.
새 검증이 포함되므로 이전 손실과 직접 비교하지 않는다.
선택은 정답 첫 응답을 제공한 후속 손실이다. 실제 사용 평가는 rollout_answer도 함께 본다.
시작 모델은 two-turn-switch-v2 epoch-03. 옵티마이저를 새로 초기화한다.
UI는 직전 문답1쌍만 전달한다. 일반 자유 대화, 장기 기억, 새로운 주제는 이번 범위 밖이다.
