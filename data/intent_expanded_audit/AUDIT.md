# 500개 문답 품질 및 분포 점검

## 확인 범위

실제 프로젝트의 data/intent_expanded/train.jsonl과 manifest.json을 읽었다. 구조·문자열 반복·말투 끝맺음·키워드 분포는 전체 500개를 검사했다. 의미 검토는 규칙에 표시된 69개와 표시되지 않은 무작위 표본 30개, 총 99개를 읽어 수행했다. 나머지 401개의 의미 적절성은 미검토다. 원본 학습 파일을 수정하거나 삭제하지 않았다.

## 전체 구조와 반복

- 기존 직접 작성 문답 50개와 공개 Chatbot_data 문답 450개다.
- 500개 모두 사용자·챗봇 메시지 1쌍이며 빈 문장은 없다.
- 구두점·공백을 제거한 질문은 500개 모두 서로 다르다.
- 같은 방식으로 정규화한 답변은 472종이다. 가장 많이 겹치는 답변은 2회다.
- 따라서 생성에서 나타난 대규모 반복을 학습 파일의 동일 답변 대량 복제로 설명할 근거는 없다.

## 말투와 주제

문장 끝의 근사 규칙으로 공개 데이터 450개 중 446개를 존댓말형으로 감지했다. 기존 50개는 비격식형 44개, 존댓말형 1개, 미분류 5개였다.

자유 대화에서 반말과 존댓말은 둘 다 가능하다. 이번 구성은 출처별 말투가 크게 달라졌다는 관찰이며, 이것이 성능 저하의 원인이라는 검증은 아니다. 후속 데이터에서는 원하는 말투를 문서에 정하고 일관성을 확인한다.

공개 450개에서 질문 키워드로 인사·대화시작 2개, 피로·수면 5개, 산책·운동 4개, 영화·문화 6개, 식물·원예 5개를 감지했다. 직장·학업 22개, 관계·연애 37개, 생활·음식·여행 50개도 감지했다. 한 문답이 여러 범주에 잡힐 수 있다.

297개는 준비한 키워드에 걸리지 않았다. 미분류는 무관하거나 품질이 나쁘다는 뜻이 아니다. 이 숫자를 실제 주제별 정답 분포로 해석하면 안 된다. 다만 추가 450개가 기존 다섯 주제마다 표현을 균등하게 보강하도록 설계된 것은 아니었다.

## 의미 검토 결과

99개를 읽고 18개에 수정안을 제안했다. 81개는 이번 검토에서 명확한 수정 사유를 찾지 못했다. 이 수치를 전체 500개의 합격률로 해석하지 않는다.

| 기존 질문과 답변 | 문제 | 제안 |
| --- | --- | --- |
| 증거도 없으면서 나만 의심해 → 평소의 행실을 되돌아보세요. | 근거 없이 사용자에게 책임을 돌림 | 억울하겠어. 어떤 상황에서 의심을 받았어? |
| 모임에서 만났어 → 꿩 먹고 알 먹고네요. | 맥락에 맞지 않는 관용구 | 모임에서 만났구나. 어떤 사람이었어? |
| 이름 알려줘 → 위로봇이요. | 다른 봇의 정체성을 그대로 학습 | 나는 네 이야기를 들어주는 챗봇이야. 편하게 말 걸어 줘. |
| 그냥 할까? → 실천이 말보다 낫죠. | 어떤 행동인지 확인하지 않고 실행 권유 | 어떤 일을 할지 고민 중이야? 상황을 조금 더 알려 줘. |
| 추천 메뉴 → 색다른걸 드셔보세요. | 요청한 메뉴가 없음 | 따뜻한 국수는 어때? 지금 어떤 음식이 당겨? |

짧은 질문·답변과 키워드 불일치는 검토 후보를 찾는 규칙일 뿐이다. 예를 들어 친구와 싸웠다는 말에 “대화로 풀어보세요”는 키워드가 달라도 관련된 응답이다. 표시된 69개를 일괄 제거해서는 안 된다.

## 다음 데이터 보강 방향

1. 전체 500개가 정제 완료됐다고 간주하지 않는다. 이번 18개 수정안은 revision_proposals.jsonl에서 원문과 비교할 수 있다.
2. 기존 다섯 주제의 질문·응답 연결을 보강하는 실험과 자유주제를 넓히는 실험을 구분한다. 동일 평가에서 무엇을 개선하려는지 기록한다.
3. 1,000개는 준비 목표다. 개수를 맞추기 위해 비슷한 문장을 복제하지 않고 상황·표현·응답 방식을 다양하게 만든다.
4. 현재 기준선의 사전학습 가중치와 학습 설정을 고정한 뒤 데이터만 바꿔 비교한다.
5. 기존 30개는 개발용으로 유지한다. 새로운 최종 평가 질문은 모델 선택이 끝날 때까지 학습·튜닝에 사용하지 않는다.

## 파일

- summary.json은 자동 집계와 의미 검토 범위를 기록한다.
- review.jsonl은 500개 모두의 원문·출처·검토 표시를 보존한다. 401개는 pending이다.
- revision_proposals.jsonl은 수정 권장 18개의 원래 답변·제안 답변·이유다.
- audit_dialogue_500.py는 전체 자동 집계를 다시 수행하는 스크립트다. 재실행하면 수동 검토 의견을 재현하지는 않는다.
