# 더 큰 SNS 말뭉치 사전학습 실험

## 이번에 확인한 데이터 규모

기존 5,000개 학습 대화는 현재 4,000개 어휘 토크나이저 기준 역할·종료 토큰 포함 394,505토큰이며, 답변 부분의 예측 대상은 172,922토큰이었다. 전체 발화 다음 토큰 예측 대상은 389,505개였다. 5회 반복은 서로 다른 텍스트의 양을 늘리는 작업이 아니다.

새 말뭉치는 동일 AI Hub ZIP의 9개 주제에서 학습 대화 50,000개, 검증 대화 5,000개를 선별했다.

| 항목 | 학습 | 검증 |
| --- | ---: | ---: |
| 대화 수 | 50,000 | 5,000 |
| 역할·종료 포함 토큰 | 5,352,204 | 534,070 |
| 다음 토큰 예측 대상 | 5,302,204 | 529,070 |
| 128토큰 블록 | 63,514 | 6,366 |

## 저장 형식

data/sns_pretrain_blocks의 train.bin과 validation.bin은 little-endian uint16, 행당 128토큰 고정 블록이다. 서로 다른 대화를 같은 블록에 합치지 않는다. 긴 대화는 블록 경계에 직전 토큰 1개를 겹쳐 다음 토큰 예측 대상을 잃지 않게 나눈다. 짧은 마지막 블록은 패딩하며 패딩은 손실에서 제외한다.

manifest.jsonl에는 원본 대화 ID와 파일, 토큰 수, 블록 위치를 기록했다. report.json의 status가 complete인 경우에만 학습기가 읽는다. 전처리와 동일한 토크나이저 파일 해시를 요구한다.

이 형식은 기존 JSONL 학습기에 직접 넣지 않는다. 동봉한 train_pretrain_blocks.py를 사용한다.

## 첫 실행

프로젝트 루트에 압축을 푼다. 기존 train_sns_30min.py와 artifacts/sns-fulltext-v1 모델이 필요하다. numpy, torch, tokenizers, transformers는 현재 가상환경을 사용한다.

~~~powershell
.\.venv\Scripts\python.exe train_pretrain_blocks.py --init-from artifacts/sns-fulltext-v1
~~~

기존 전체 발화 모델의 가중치에서 시작하고 옵티마이저는 한 번 새로 초기화한다. 기존 모델은 그대로 보존하며 새 결과는 artifacts/sns-pretrain-blocks-v1에 저장한다.

## 다음 실행

~~~powershell
.\.venv\Scripts\python.exe train_pretrain_blocks.py --resume
~~~

실행 예산의 약 20분을 학습에 사용하고 나머지는 검증·저장에 배정한다. 실행마다 데이터 순서를 새로 시작하지 않고 저장된 순서와 위치, 옵티마이저, 난수 상태에서 이어간다. 100스텝마다 원자적으로 checkpoint.pt를 교체한다. Ctrl+C 시 마지막 완전 저장 스텝에서 재개한다.

검증 시간은 매번 동일하게 고른 1,024개 블록으로 제한한다. 이 검증 손실은 전체 발화 지표이며, 과거 답변 부분 손실 및 다른 데이터셋의 손실과 직접 비교하지 않는다. 검증이 완료되고 손실이 개선되면 models/step-...에 모델과 토크나이저를 보존한다. 최선 모델은 training_log.json의 best_model에 기록된다.

한 번에 전체 말뭉치 1회를 완료하지 못할 수 있다. 추가 실행마다 같은 명령으로 이어가고, 매번 생성 답변도 별도로 관찰한다. 30분은 목표 예산이며 진행 중 연산·저장 시간에 따라 차이가 있다.

## 검증 범위와 한계

- 55,000개 원본 대화 ID와 토큰화 내용의 중복이 없음을 확인했다.
- 전체 파일 크기, 토큰 ID 범위, 블록 위치, 예측 대상 수를 검사했다.
- 작은 말뭉치로 배치 학습, 검증, 저장·재로딩을 확인했다.
- 연속 4스텝과 2스텝 저장 후 2스텝 재개의 모델 가중치 일치를 확인했다.
- 전체 확대 말뭉치 학습과 생성 품질은 아직 측정하지 않았다.
- 9개 주제의 앞부분에서 조건 통과한 대화다. 무작위 대표 표본이나 사람의 전체 품질 검수를 거친 자료가 아니다.
- 기존에 짧은 응답만 남겼던 필터와 달리 전체 대화를 활용하므로 데이터 수뿐 아니라 길이와 문맥 분포도 달라진다.
- 535만 토큰도 자유주제 대화 능력을 보장하는 규모는 아니다. 추가 학습을 통해 반복과 질문 관련성이 실제 개선되는지 판단한다.

## 말뭉치 재생성

데이터는 이미 포함돼 있으므로 재생성 명령은 다시 선별할 때만 사용한다. 출력 경로는 기존 폴더와 다른 이름을 지정한다.

~~~powershell
.\.venv\Scripts\python.exe prepare_pretrain_blocks.py --output data/sns_pretrain_blocks_rebuilt
~~~
