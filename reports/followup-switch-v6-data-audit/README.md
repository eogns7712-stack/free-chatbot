# v6 학습 데이터 검사 결과

대상: data/followup_switch_v6. 원본 수정·학습 없음. evaluation/audit_dialogue_data.py로 생성한 audit.json에 파일 해시와 상세 내역이 있다.

## 확인한 사실

- 학습435개. 완전 동일 대화 중복 그룹0개.
- 학습/검증/비교 사이 전체 대화 및 전체 사용자 발화 순서의 정규화 정확 중복0개. 의미 중복 검사 결과는 아니다.
- 같은 전체 입력 문맥에 다른 학습 답변이 붙은 경우3개. 산책·인사·졸림의 같은 첫 사용자 문장에 각2종의 답변이 있다. 모두 관련된 표현 변형으로 명확한 의미 모순은 확인하지 않았다. 자동 conflict 표시는 문자열 차이 후보라는 의미다.
- 같은 사용자 문장별 답변 차이5개 중 응/맞아의 차이는 앞선 문맥에 따른 정상적인 목표다. 이를 단일 답변으로 통합하면 안 된다.
- assistant 학습 노출721회, 마스킹된 이전 assistant70회. 노출 횟수는 실제 토큰 손실 비중과 같지 않다.
- 종료 답변은4개이며 모두 단문 대화다. 식물 발화에 종료 답변이 직접 붙은 학습 예시는 발견하지 않았다. 추론 중 종료 답변이 나오는 원인이 잘못된 라벨이라는 증거는 없다.
- 첫 응답을 실제 학습하는 동일 사용자 문장의 반복: 신규 영화·식물·산책 문맥 각각32회, 기존 산책·졸림 각각31회, 인사30회. 대화 전체는 달라도 첫 구간이 반복되어 노출이 집중된다.
- 검증·비교 각각93개 중85개는 첫 사용자 문맥을 이미 학습했다. 마지막 답변 직전 전체 문맥의 정확 중복은0개다. 첫 응답6/6 같은 수치를 미학습 첫 표현에 대한 일반화로 해석하면 안 된다.

## 해석과 다음 비교

명백한 상반 라벨 충돌이 주원인이라는 증거는 찾지 못했다. 문맥별로 올바른 다중 답변과 관련된 표현 변형은 보존한다. 반복된 첫 구간의 학습 노출 편중과 첫 문맥 공유 평가의 범위가 확인됐다. 이 사실만으로 편중이 퇴보의 원인이라고 확정할 수 없다.

다음 실험 후보는 데이터 문장을 추가하지 않고, 반복되는 동일 첫 입력·정답 구간의 학습 횟수를 제한하는 조건이다. 후속·전환 목표는 유지하고 반복된 첫 assistant만 일부 마스킹하는 방식으로 전체 학습과 비교할 수 있다. 변경 횟수·손실 토큰 수를 기록하고, 기존 v6와 같은 시작 모델·시드·순서·회차로 비교한다. 기존 last_assistant 설정은 유지한다.

실행 전에는 마스킹으로 후속 목표가 제거되지 않는지 확인하고, 학습에 쓰지 않는 새 첫 표현 평가를 먼저 고정해야 한다. 원래 문맥 공유 평가와 새 표현 평가를 나눠 판단한다. 이 문서는 검사 및 후속 설계이며 다음 학습 조건은 아직 구현·실행하지 않았다.
