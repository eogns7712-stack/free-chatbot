# CPU 30분 예산 학습 실험

프로젝트 루트에 압축을 풀고 다음 명령을 실행합니다.

~~~powershell
.\.venv\Scripts\python.exe train_sns_30min.py
~~~

## 데이터와 모델

- 학습 5,000개, 검증 450개. 9개 주제별 수량을 나눠 선별했습니다.
- 원본 대화 ID와 동일 메시지 내용이 두 분할에 겹치지 않는지 확인했습니다.
- 전처리와 학습에 artifacts/sns-tokenizer-v1/tokenizer.json을 사용합니다.
- 토크나이저 파일 해시가 달라지면 학습을 중단합니다.
- 모델은 무작위 가중치로 초기화합니다. 4층·128차원, 4 heads, 문맥 128토큰, 약 132만 파라미터입니다.
- 배치 4, 최대 5회, 학습률 0.0003, CPU 스레드 4입니다.
- 사용자 발화와 패딩은 손실에서 제외하고 챗봇 답변과 종료 토큰을 학습합니다.
- 학습·검증 손실은 답변 토큰 수로 가중 평균합니다.

## 시간과 저장

실행 시작 20분을 기준으로 새 학습 스텝을 중단하고, 28분까지 검증을 진행할 수 있도록 했습니다. 남은 시간은 저장에 사용합니다. 진행 중 연산과 저장은 종료될 때까지 시간이 걸리므로 30분은 목표 예산입니다.

- artifacts/sns-30min-v1/는 검증 손실이 가장 낮은 모델입니다.
- 그 안의 latest/는 500스텝마다 및 정상 종료 시 저장한 최근 모델입니다.
- training_log.json에 설정과 데이터 해시, 검증 손실, 선택 스텝, 실제 경과 시간을 남깁니다.
- latest는 모델 가중치 저장용입니다. 옵티마이저 상태를 포함하는 중단 지점 재개 기능은 없습니다.
- 같은 출력 폴더가 이미 있으면 중단합니다. 다시 실험할 때는 --output artifacts/sns-30min-v2처럼 새 경로를 지정합니다.

## 전처리 재실행

데이터는 이미 포함돼 있습니다. 재생성할 때만 새 출력 경로를 지정해 실행합니다.

~~~powershell
.\.venv\Scripts\python.exe prepare_sns_30min.py --output data/sns_30min_rebuilt
~~~

주제별 앞부분에서 조건을 통과한 대화를 사용했습니다. 임의 표본이며 의미·사실성 검수는 자동화하지 않았습니다. report.json에 주제별 선별 통계, manifest.jsonl에 원본 ID와 토큰 수를 기록했습니다.

## 검사 범위

전체 5,450개의 역할 순서, 토큰 한도, 분할 간 원본 ID·내용 중복을 확인했습니다. 소량 데이터로 배치 학습, 검증, 패딩 마스킹, best/latest 저장, 재로딩을 검증했습니다. 전체 30분 실행 결과와 실제 대화 품질은 실행 후 평가합니다.
